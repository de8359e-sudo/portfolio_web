1 진행 배경 및 문제 의식

백오피스 시스템의 부재
  • 상점 런칭마다 반복되는 하드코딩 개발 (건당 4주 소요)
  • 통합 관리 도구 부재로 운영 효율성 저하
  • 신규 기능 업데이트 시 마이그레이션 부담
결제 유도 시스템 부재
  • 결제 유도 장치 부재로 인한 매출 기회 손실
  • 프로모션에 필요한 쿠폰, 포인트 기능 니즈 증가(운영)
상품 정보 확인 및 결제 상세 정보 확인 구좌 부재
  • 구매 결정 과정 중 이탈 발생
  • 수량 선택 기능 부재로 인한 결제 피로도 증가

2 해결 과정

STEP 1 - 기본 문서 정리
  • 백오피스로 구현할 기능 정의
    • 기존 웹 상점에서 백오피스 기능화가 필요한 영역 구분
    • PRD 및 기능명세서 작성
    • 문서 구체화 과정 중 AI 활용
  • E-Commerce 서비스 벤치마킹
    • 상품 탐색 ~ 구매까지의 플로우 탐색
    • 쿠폰, 포인트 사용 케이스 조사
    • 글로벌 커머스 사례 조사
STEP 2 - 유관부서 논의
  • 기능명세서 공유 및 개발 방식 논의
  • 쿠폰/포인트 적용 시 글로벌 대응 정책 마련
    • 통화별 예외 처리 케이스 확인
    • 운영 정책 및 프로세스 논의
STEP 3 - 기획서 작성
Front Office
  • 단계별 정보 위계 최적화를 통한 구매 프로세스 개선
    • 상품 상세 페이지 신설
    • 주문서 페이지 신설 및 쿠폰/포인트 기능 적용
  • 글로벌 정책 및 UI 적용
    • 쿠폰/포인트 기능 제공 시 통화별 예외 케이스 확인
    • 국가별 법률 확인 및 유의사항 적용
    • 16개 언어 번역 적용
Back Office
  • 운영 스타일 반영한 UI/UX 설계
    • 상품 등록과 프로모션 기능 분리하여 모듈화된 프로세스 제공
    • 모든 웹 상점에 공통 반영 되는 컨트롤 타워 메뉴와 개별 웹 상점별 메뉴 분리
  • 웹 상점 커스터마이징 자율도 극대화↑
    • 상품 및 프로모션 관리, 로고/배너 이미지 관리, 메타 태그, ... 등 운영에 필요한 모든 영역 컨트롤
    • 국가별 제도 변경 시 빠른 대응을 위한 유의사항 안내문 설정
